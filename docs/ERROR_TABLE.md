## 结论

- 缺陷A（输入解释）：跳过 sRGB EOTF 导致 Gamma 叠加，暗部整体抬升发灰，
  误差集中在暗部渐变组。修复：输入必须经 sRGB EOTF 解码到线性光。
- 缺陷B（中间域）：在 ACEScg 域裁剪负值会破坏宽色域内容的色相。
  修复：中间域全程保留负值，仅最终显示量化时可裁剪到 [0,1]。
- 缺陷C（位深路径）：16-bit 路径只取高字节，暗部细渐变出现带状量化。
  修复：16-bit 样本按 65535 归一化，全程 float64 计算。
- 曝光补偿是线性域创意控制（2^stops 倍增），不得用于掩盖上述
  传递函数错误；修复后暗部不再需要曝光抬升来“找回”灰平衡。
