# 5.1.4 与简化双耳空间渲染

这个 Go 包把一组 channel-based bed 和动态对象映射为扬声器线性增益。它只依赖
Go 标准库，输出确定性的渲染计划，不直接处理 PCM 采样。

坐标是听众局部坐标，单位为米：

- `+X`：右
- `+Y`：上
- `+Z`：前
- 听众位于原点并朝向 `+Z`

## 布局

`Standard514()` 提供 10 个输出通道：

| 通道 | 方位角 | 高度角 |
|---|---:|---:|
| `L`, `R` | ±30° | 0° |
| `C` | 0° | 0° |
| `LFE` | 非方向通道 | - |
| `Ls`, `Rs` | ±110° | 0° |
| `TFL`, `TFR` | ±45° | 45° |
| `TBL`, `TBR` | ±135° | 45° |

`BinauralSimple()` 提供位于 ±30° 的 `L`、`R` 两个虚拟扬声器，没有高度维。
它是简化的双耳折叠，不包含 HRTF，也不产生 ITD。

## 声源到扬声器的增益

对动态对象位置 `p`，先取单位方向 `u = p / ||p||`。对每个非 LFE 扬声器方向
`s`，计算：

```text
w(s) = exp(k * (dot(u, s) - 1))
k    = 32
```

去掉低于最大权重 `1e-9` 的旁瓣后，以 L2 能量归一化：

```text
g(s) = w(s) / sqrt(sum_i w(s_i)^2)
```

因此同一个对象的所有扬声器贡献满足 `sum(g(s)^2) = 1`。重叠扬声器的相加发生在
输出总线：不同对象、bed 和对象落在同一通道时直接线性相加，不覆盖已有贡献。
LFE 不参与对象声像，避免把方向性对象错误送入非方向通道。

`SourceResult.Contributions` 保存每个输入的完整增益，`Mix.Speakers` 保存所有输入的
总和。`Mix.Peak` 是总和中的最大值，便于调用方判断是否需要总线衰减。

bed 的处理分两种：

- 5.1.4 使用 `BedDirect`，通道同名直达对应扬声器，增益为输入增益。
- 双耳布局使用 `BedFold`，从标准 5.1.4 的标称方向折叠到 `L`、`R`。

## 距离衰减

对象距离为 `d = ||p||`，线性距离增益为：

```text
D(d) = 1         , d <= 1 m
D(d) = 1 / d     , d > 1 m
```

这对应自由场的声压幅度 `1/r` 模型，并避免 1 米内出现非物理增益提升。对象最终
总能量为 `(inputGain * D(d))^2`。距离只改变幅度，不改变方位。bed 是已经分配好
声道的总线内容，不做距离衰减。

## 高度缺失降级

当布局的 `HasHeight == false` 时：

1. 丢弃单位方向的 `Y` 分量。
2. 对剩余水平分量重新归一化，保持原有方位角。
3. 在 `HeightLossDegrees` 中记录丢失的高度角。
4. 添加 `height_folded` 告警。

如果水平分量本身为零，例如正上方或正下方的对象，则方向降级为 `+Z` 前方，并
添加 `height_only_folded_front` 告警。不能从垂直方向编造一个左右方位；前方是
明确、稳定且不依赖坐标正负号的回退。

双耳布局的 5.1.4 bed 也按标称高度方向折叠，因此顶部 bed 通道会保留左右侧信息，
但高度信息被显式记录为丢失。双耳布局没有 `LFE` 通道时，LFE 以等功率方式铺到
非 LFE 扬声器，并添加 `lfe_omni` 告警。

## 越界对象

对象没有房间边界参数，位置可以超出扬声器包围范围。渲染器不把坐标裁剪到某个
盒体，而是先归一化方向，再按方向求声像；只有距离进入距离衰减。因此 100 米外
右侧的对象和 1 米右侧对象具有相同方位，只有幅度不同。

不能把越界对象直接居中。居中会把真实方位 `+X`、`-X` 或斜后方都压成同一个
幻象中心，破坏方位连续性，使不同对象错误重合，并让后续距离变化无法恢复方向。
中心只适合“确实没有方向”的输入，例如对象正好位于听众原点。

## 不可表达对象

- 位于原点的对象：使用所有非 LFE 扬声器的等功率全向回退，并添加
  `no_direction` 告警。
- 布局半球内没有扬声器覆盖的对象：保留最近能量分布，并添加
  `outside_speaker_coverage` 告警。例如 5.1.4 的正下方对象，或只有前方虚拟
  扬声器时的后方对象。
- 非有限坐标、非有限增益、负增益、未知 bed 通道：返回错误，不产生带 `NaN`
  或静默丢失的混音。

## 使用

```go
layout := spatial.Standard514()
renderer, err := spatial.NewRenderer(layout, spatial.Config{})
if err != nil {
	log.Fatal(err)
}

mix, err := renderer.Render(spatial.Scene{
	Bed: []spatial.BedChannel{
		{Channel: spatial.ChannelC, Gain: 0.5},
	},
	Objects: []spatial.Object{
		{ID: "voice", Position: spatial.Vec3{X: -1.2, Y: 0.7, Z: 2}, Gain: 0.8},
	},
})
if err != nil {
	log.Fatal(err)
}

for _, speaker := range mix.Speakers {
	fmt.Printf("%s %.6f\n", speaker.Speaker, speaker.Gain)
}
```

## 验证

运行：

```sh
go test ./...
```

测试覆盖：

- 非对称坐标及左右镜像；
- 多个扬声器的重叠权重与 L2 能量归一化；
- bed 重复通道、bed 与对象、对象与对象落在同一扬声器时的线性相加；
- 1 米内、1 米和远场的距离衰减；
- 越界位置保持方位、只改变距离增益；
- 双耳高度折叠、纯垂直方向回退；
- 原点对象、无半球覆盖、非法坐标/增益和未知通道。
