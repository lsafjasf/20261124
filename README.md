# timemap

变速片段的「源时间 ↔ 序列时间」可重复映射表，纯 Go 标准库实现（仅依赖
`math/big`、`errors` 等），无第三方依赖。

## 模型

映射由关键帧 `Keyframe{At, Source}` 定义，均为精确有理数秒值：

- 相邻关键帧之间为线性段，斜率即局部速度。
- 正斜率：正向播放；负斜率：反向播放；零斜率：冻结。
- 相邻段斜率可以不同，天然表达速度突变（含方向反转）。

每个输出帧生成一行 `FrameMapping`：

- `SourceFrame = floor(sourceTime * SourceRate)`，命中片段末点时回退到最后一帧。
- `AudioSample = floor(sourceTime * AudioRate)`，精确命中总采样数时回退一个样本；
  `AudioPosition` 保留未取整的精确采样位置。
- `SourceTime` / `OutputTime` 保留 `*big.Rat` 精确值。

## 精确性与可重复性

构建时求所有帧率分子/分母、关键帧时间分母的最小公倍数，得到统一整数刻度域
`ticks/sec`（默认上限 20 亿，可用 `Spec.MaxTicksPerSec` 调整）。所有插值在
整数刻度与 `math/big` 有理数中完成，24、30、30000/1001（29.97）等帧率不会产生
浮点漂移；同一 `Spec` 多次构建结果逐行一致（见 `TestDeterministicAcrossBuilds`）。

## 拒绝规则

`Build` 在返回前完成结构校验与逐行校验，非法输入不会产生部分结果：

- 非单调：关键帧输出时间必须严格递增（`ErrNonMonotonic`）；同一线性段内源时间
  也必须沿该段方向单调。
- 越界：关键帧源时间必须落在 `[0, SourceFrames/SourceRate]`；每个输出帧映射后的
  源时间、源帧号、音频样本同样逐行检查（`ErrOutOfBounds`，错误携带输出帧号）。
- 亚帧循环：被两次方向变化夹住的内部折返，若位移小于一个源帧周期，则拒绝
  （`ErrSubFrameLoop`）；夹在中间的零速冻结视为零位移内部折返，同样拒绝。
  首尾开放端的冻结、以及位移达到整帧的反向回放均合法。
- 刻度域无法在 int64 内表示时返回 `ErrTickOverflow`。

## 测试

```
go test ./... -v
```

覆盖：24→30 正向/冻结/反向/速度突变、拒绝路径（非单调、越界、亚帧循环、内部
冻结、超界输出帧）、29.97 精确帧率与混合变速、1 小时 24→30（108000 行）与
10 分钟 29.97 长片段、跨构建可重复性，以及两个可运行的 `Example`。
