# logfit — Log 曲线反推拟合实验

从相机技术员记录的「码值 ↔ 线性亮度」采样对，反推 Log 曲线的
黑点、中灰、肩部工作点，并给出参数的可辨识区间。仅使用 Go 标准库。

## 模型

统一五参数形式（码值归一化到 0..1，线性域 0.18 = 中灰）：

```
L >= t:  V(L) = A*log10(L+B) + C     (log 段，含肩部滚降)
L <  t:  V(L) = S*L + K              (线性趾部，截点处 C0 连续)
```

`slog3` / `vlog` / `logc` 三种风格共用该形式，仅 MAP 先验中心不同
（先验中心取各自官方曲线参数）。先验兼作岭正则：样本充足时数据主导，
样本稀少时防止参数发散、抑制过拟合。

## 用法

```sh
go build -o logfit .
./logfit -model slog3 -data samples.csv        # 拟合实测 CSV
./logfit -model vlog  -demo -n 12 -noise 0.004 # 合成数据自检
```

CSV 每行 `code,linear`（归一化码值,线性亮度），首行表头可省略。

## 输出说明

- **拟合参数**：5 个自由参数的 MAP 估计与 68% 剖面 SSE 区间
  （固定该参数、重优化其余参数，Δχ²=1 阈值）。区间一侧标 `*` 表示
  该侧在扫描范围内不可辨识——数据无法区分该方向的参数变化
  （例如缺少趾部采样时，截点 t 与趾部斜率 S 不可区分）。
- **导出工作点**：黑点 V(0)、中灰 V(0.18)、肩部 V(0.9)，
  delta 法 ±1σ（协方差含先验精度项）。
- **残差**：逐点残差与标准化残差。
- **过拟合诊断**：训练 RMSE、留一交叉验证 RMSE、AICc，
  以及 n≤p / n<2p / LOO 恶化告警。
