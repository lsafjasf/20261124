# 字幕显示决策器

纯 Go 实现的字幕轨选择器。同一时刻存在三条可用轨时——
**强制叙述（Forced Narrative）、完整字幕（Full）、SDH 听障字幕**——
依据用户偏好、轨道类型和当前窗口的可读空间选出一条（或决定不显示）。

## 决策规则

### 1. 常规字幕选择（`full` / `sdh`）

当且仅当用户打开主字幕开关，且候选轨在当前时刻有命中的提示（cue）时参与排序：

1. **语言优先**：用户 `PreferredLanguages` 中排名靠前的语言优先；
   匹配按语言主标签比较（`zh-Hans` 与 `zh-CN` 视为同语言）。
2. **偏好语言优先于任意非偏好语言**；都不在偏好列表时作为语言回退（`language_fallback`）。
3. **类型次序**：开启 `SDHMode` 时 `sdh` 优先于 `full`；关闭时反过来。
4. **可读空间过滤**：按等宽单元格折行后，宽度与行数都能放进
   `ReadableSpace` 的候选才视为可显示；存在可显示候选时，
   从排序最高的可显示候选中选择。
5. **全部放不下**：保留排序最高的轨道并返回，`Fits=false`、
   `Overflow>0`，由渲染层决定缩放字号或截断；强制轨不会在此时接管。

### 2. 强制叙述何时必须优先

强制轨表达的是外语对白、屏幕标牌等“即使关闭字幕也必须翻译”的内容，
因此满足以下**全部条件**时它必须被选中，与主字幕开关无关：

- 该强制轨在当前时刻有命中的提示；
- 强制轨配套的音轨语言与当前音轨语言一致（未声明配套语言时不做此校验）。

两种触发原因：

- `forced_only`：主字幕关闭，强制轨独立承担翻译；
- `forced_override`：主字幕开启，但当前时刻没有任何常规轨的提示命中，
  强制轨临时接管（常规提示出现后立即让回常规轨）。

强制轨**不受可读空间否决**：空间不足时仍然返回，仅通过
`Fits`/`Overflow` 标记，因为漏掉强制字幕属于内容缺失。

### 3. 不显示

没有任何轨道命中提示，或仅有的强制轨与当前音轨语言失配时，
返回 `Reason=none`、`Track=nil`。

## 可读空间模型

- 空间以字符单元格表示：`WidthCells`（每行格数）与 `HeightLines`（行数）。
- 东亚宽/全角字符计 2 格，其余计 1 格（见 `CellWidth`）。
- `WrapLine` 先按词折行，超长单词硬折；折行后的总行数与最大宽度
   与可读空间比较得到 `CueFit`。

## 重算入口

`Decider` 缓存最近一次播放状态，环境变化时基于缓存立即重算：

- `ChangeAudio(language)`：切换音轨语言，强制轨的语言匹配条件随之变化；
- `Resize(space)`：窗口尺寸变化后重新折行与适配；
- `SetPreferences(prefs)`：偏好（总开关、SDH、语言序）变化后重算；
- `Decide(state)`：播放位置推进或外部状态整体更新。

无状态纯函数 `Decide(tracks, prefs, state)` 提供同样的规则，
便于在无缓存场景直接调用。

## 运行

```bash
go test ./...        # 表驱动单测，含音轨切换与窗口重算场景
go run ./cmd/demo    # 六步决策演示
```
